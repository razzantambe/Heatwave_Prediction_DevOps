# Heatwave Prediction — Part ABCD (DevOps)

This folder contains the DevOps-ready Flask prediction service.

## 1. Generate the model
The model file is generated locally by running:

```bash
pip install -r requirements.txt
python train.py
```

This creates `model/heatwave_model.pkl`. The training data is the small teaching dataset from the supplied lab manual.

## 2. Run locally (without Docker)

```bash
python app.py
```

Open http://localhost:8000

Test the API:

```bash
curl -X POST http://localhost:8000/predict -H "Content-Type: application/json" -d "{\"max_temp\":45,\"min_temp\":31,\"humidity\":50,\"wind_speed\":7,\"previous_temp\":44}"
```

## 3. Build and run Docker

Run these commands from this project directory:

```bash
docker build -t heatwave-api:1.0 .
docker run -d --name heatwave-container -p 8000:8000 heatwave-api:1.0
```

Open http://localhost:8000

To stop the container:

```bash
docker stop heatwave-container
docker rm heatwave-container
```

## 4. Push to GitHub

Create an empty GitHub repository named `heatwave-mlops`, then run:

```bash
git init
git add .
git commit -m "Add heatwave prediction DevOps project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/heatwave-mlops.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## 5. Verify GitHub Actions

Open the repository on GitHub, select **Actions**, and open the **Heatwave ML CI** workflow. A push or pull request to `main` triggers dependency installation, model training, and Python syntax checks.

This workflow implements CI checks; it does not automatically deploy to a production server.

## Project flow

Machine Learning → MLflow experiment tracking → Flask API → GitHub → Docker → GitHub Actions CI.

**Note:** The model is generated by `python train.py` and is intentionally not included as a prebuilt binary in the ZIP.
